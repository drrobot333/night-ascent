# 야간 산행 — NIGHT ASCENT

헤드랜턴 하나로 두 사람이 밤 산을 오르는 1인칭 협동 공포 게임. 브라우저(WebGL)에서 바로 실행됩니다.

## 실행

```bash
npm install
npm run dev        # http://localhost:5173
```

배포용 정적 파일:

```bash
npm run build      # dist/ 생성 → Netlify, Vercel, GitHub Pages 등 어디든 업로드
npm run preview    # 빌드 결과 미리보기
```

## 게임 규칙

- 등산로를 따라 **돌탑(체크포인트)** 을 지나 정상 대피소까지 오릅니다.
- 랜턴은 하나뿐입니다. **빛이 닿는 곳만 안전**합니다. 어둠 속에 오래 있는 사람이 표적이 됩니다.
- 랜턴을 든 사람이 **괴물을 비추면** 괴물은 얼굴을 가리고 물러납니다.
- 길가의 **배터리**를 주워야 랜턴이 꺼지지 않습니다. 배터리는 랜턴을 든 사람이 집습니다.
- 둘 중 한 명이 붙잡히면 마지막 돌탑에서 다시 시작합니다.
- **위험 구간**(징검다리, 너덜지대, 썩은 통나무)에서는 자기 발밑이 비춰질 때만 움직일 수 있습니다. 랜턴 든 사람이 파트너 발밑을 비춰 먼저 건너게 한 뒤, 고개를 숙여 자기 발밑을 보며 건너야 합니다.
- **잠긴 철문**: 레버가 숲속 어둠 15m 안쪽에 있습니다. 한 명이 케이블을 따라 들어가 당기는 동안 다른 한 명이 멀리서 비춰줘야 합니다.
- **쓰러진 나무**: 윈치를 9초간 돌리는 동안 움직일 수 없고, 그 사이 "그것"이 반드시 다가옵니다. 다른 한 명이 지켜야 합니다.

## 조작

| 키 | 동작 |
|---|---|
| WASD | 이동 |
| Shift | 달리기 (스태미나) |
| 마우스 | 시선 |
| E | 랜턴 건네기 / 받기, 배터리 집기 · 길게 누르면 레버 당기기 / 윈치 돌리기 |
| F | 랜턴 켜기 / 끄기 |
| Q | 보고 있는 곳 가리키기 (파트너에게 신호) |
| Esc | 일시정지 |

## 모드

- **혼자 오르기**: AI 동반자가 따라옵니다. 랜턴을 넘기면 동반자가 앞장서서 길을 비춥니다.
- **방 만들기 / 참가하기**: 서버 없이 WebRTC(PeerJS 공개 브로커)로 2인이 연결됩니다. 방장이 4자리 코드를 친구에게 알려주면 됩니다.

## 기술

- Three.js r169, Vite 5
- 절차 생성: 지형(심플렉스 노이즈 + 등산로 절삭), 숲(인스턴싱 수천 그루), 하늘(셰이더), 안개(조명을 받는 빌보드)
- 헤드랜턴: 그림자를 드리우는 SpotLight + 볼류메트릭 빛줄기 + 배터리/깜빡임
- 후처리: 블룸, 필름 그레인, 비네트, 색수차, 색보정, 레트로 모드(저해상도 픽셀 + 디더링 + VHS 노이즈)
- 사운드: 전부 WebAudio로 합성 (바람, 발소리, 심장박동, 괴물, 스팅어) — 외부 에셋 없음
